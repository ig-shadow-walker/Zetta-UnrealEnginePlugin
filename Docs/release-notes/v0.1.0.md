**Zetta 3D for Unreal Engine 0.1.0** — the first release (beta). 3D models and an AI agent, inside the Unreal Editor.

## Downloads

| Platform | File | Status |
|---|---|---|
| **macOS** (Apple Silicon and Intel) | `Zetta3D-0.1.0-UE5.8-Mac.zip` | ✅ Available — attached below |
| **Windows** | `Zetta3D-0.1.0-UE5.8-Win64.zip` | 🔜 **Coming soon** — until then, build from source with Visual Studio |
| **Linux** | — | Build from source |

For **Unreal Engine 5.8**. The macOS zip has prebuilt binaries, so it works in Blueprint-only projects — no C++
toolchain needed.

## Install (macOS)

1. Download `Zetta3D-0.1.0-UE5.8-Mac.zip` below.
2. Unzip it into your project's `Plugins` folder, so you have `YourProject/Plugins/Zetta3D/Zetta3D.uplugin`.
3. Open the project. The **Zetta 3D** window opens on its own — click **Sign in with your browser**, then
   **Connect Unreal Engine** on zetta3d.ai.

**Windows or Linux today:** clone the repository into `YourProject/Plugins/Zetta3D` in a project with C++ in it and open
it; Unreal offers to build the plugin.

## What's in it

- **3D Studio** — Generate 3D (Zetta N2.5), Smart 3D (Zetta Np1 and Np1.5), Segment, Retopology, Smart UV, Texture,
  Auto Rig (UE5 Mannequin skeleton by default) and the Image Studio, with live prices and your plan's options.
- **My Generations** — your library: import, place in the level, drag into the level, send to a tool, fork; pipeline
  runs as one tile.
- **3D Pipelines** — the node canvas, Describe it, runs on up to 20 seeds, and importing their results.
- **The Zetta Agent** — works in your level, Blueprints, materials and C++, compiles what it writes (Live Coding on
  Windows, hot reload on macOS), checks its work in the viewport, and makes 3D models and pictures. Every change can be
  undone. Runs on your Zetta account, or on your own Gemini, OpenAI, DeepSeek, Claude, GLM or Meta API key.
